# Matching inference promotion evidence

Status (2026-07-30): the `0.7.0a4` publication-scale coverage and real-data design-
sensitivity certificate passes. This evidence promotes the validation record for the two
already implemented analytical paths. It does not broaden their public boundaries and
does not change the default `inference="none"`.

## Decision and claim boundary

The promotion gate had two credible designs:

1. attach analytical inference to every support/caliper sensitivity specification; or
2. keep inference coverage and target-changing design sensitivity separate.

The first design is invalid under the maintained contract: support and caliper rules can
select focal observations and change ATT, ATC, or ATE into a retained-overlap estimand.
CauseKit therefore uses the second design. Coverage is evaluated only with
`caliper=None` and `common_support=None`. Real-data sensitivity reports point estimates,
target labels, attrition, reuse, ties, and balance with `inference="none"`.

The certificate is [matching_promotion_evidence.json](../benchmarks/matching_promotion_evidence.json),
generated by [validate_matching_promotion.py](../benchmarks/validate_matching_promotion.py).
The saved generator SHA-256 is
`27d1e885d535cc54324e071283820e3bdda63abcbecba9b5e8cc6f809915720e`;
the certificate SHA-256 is
`df79d8c75edd369ab9f8bae875b026f007e124698684c82f15c7cdc7a93cbfbd`.

## Monte Carlo contract

The deterministic design uses 1,000 replications for each of two overlap settings and 500
observations per replication. Every replication fits ATT, ATC, and ATE under both:

- a known true propensity with `inference="abadie_imbens"`; and
- a correctly specified, independently fitted full-sample unpenalized Logit MLE with
  `inference="abadie_imbens_estimated"`.

This is 2,000 generated datasets and 12,000 matching fits. Treatment follows
`Bernoulli(expit(beta * X))`, with `X ~ Uniform(-1, 1)`. Favorable overlap uses
`beta=0.5`, giving theoretical propensities from `0.378` to `0.622`; stressed overlap
uses `beta=2.2`, giving `0.100` to `0.900`. The untreated outcome is nonlinear and
heteroskedastic, while the treatment effect is the constant truth `1.5`. Constant truth
keeps the ATT, ATC, and ATE reference values exact while still exercising separate focal
populations and variance formulas.

The preregistered gates were coverage in `[0.90, 0.99]`, mean analytical SE divided by
the empirical sampling SD in `[0.75, 1.25]`, absolute bias no greater than `0.08`, zero
refusals, and 1,000 completed replications per cell. Coverage Monte Carlo uncertainty is
reported rather than hidden.

## Hash-verified real-data sensitivity

The point-estimation sensitivity uses all 4,642 rows of the pinned Stata Press
`cattaneo2` file (SHA-256
`631e926eb9981828ba2e542b32c16ae08f336b9efa10621651a8a185405e0577`). A
full-sample unpenalized Logit fits maternal smoking on an intercept, marital status,
maternal age, maternal education, and first-birth status. Its fitted propensity range is
`0.0569–0.7236`. Matching uses logit-propensity distance, replacement, one requested
neighbor, and deterministic fractional boundary ties.

The logit-score standard deviation is `0.69690`. The three caliper widths are `0.06969`
(`0.1 SD`), `0.13938` (`0.2 SD`, the default), and `0.20907` (`0.3 SD`). They are compared
with no caliper/no support restriction and no caliper/intersection support.

| estimand | estimate range across five designs | span | target/attrition finding |
| --- | ---: | ---: | --- |
| ATT | -243.689 to -243.536 | 0.153 | all 864 treated focal units retained |
| ATC | -196.776 to -196.432 | 0.344 | support removed 10 controls; narrow caliper removed 3 more |
| ATE | -205.498 to -205.228 | 0.271 | support/caliper rules changed the full-sample target |

The maximum post-match absolute standardized mean difference across the five designs was
`0.0312`. Numerical stability and observed balance do not establish conditional
exchangeability or address unmeasured confounding. The ATC/ATE support rows are explicitly
labelled `atc_matched_support`/`ate_matched_support`; they are not silently compared as the
same population target.

## Reproduction

Install the validation extra, make the pinned Cattaneo file available through CauseKit's
verified cache, and run from the repository root:

```bash
python -m pip install -e ".[validation]"
python benchmarks/validate_matching_promotion.py \
  --replications 1000 --nobs 500 --workers 8
python -m pytest tests/validation/test_matching_promotion.py -q
```

Add `--download` only when explicit HTTPS acquisition is intended. Worker count affects
elapsed time but not replication seeds or results.

## Pre-mortem and remaining refusals

| Failure | Evidence signal | Maintained response |
| --- | --- | --- |
| Weak overlap degrades finite-sample inference | bias, coverage, or SE ratio leaves its gate | retain failure; do not average it away across overlap designs |
| Sensitivity silently changes the estimand | focal fraction below one or support exclusion | retain realized target label and prohibit analytical inference |
| Parallel execution changes results | certificate differs across worker counts | spawn one deterministic seed per replication before dispatch |
| A plausible bootstrap masks matching non-smoothness | resampled SE appears in the runner | prohibit ordinary bootstrap; exercise only analytical contracts |
| Real-data stability is overinterpreted | small estimate span treated as identification | report it only as design sensitivity and preserve causal caveats |

Generic, cross-fitted, penalized, probit, target-selected, tied-boundary, clustered,
paired, survey, and multiway matching inference remain outside this promotion. No gate was
weakened to obtain the certificate.
